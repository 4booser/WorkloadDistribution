# WorkloadDistribution

Консольний C++ проект для курсової роботи з теми:
Автоматизована інформаційно-пошукова система «Розподіл учбового навантаження».

## Структура проекту

- main.cpp — головний цикл програми та обробка меню.
- models.h — структури Teacher, Subject, Group, Workload.
- data.h, data.cpp — додавання даних, пошук, перевірка id, розрахунок годин.
- ui.h, ui.cpp — введення, меню, прості функції виведення.
- report.h, report.cpp — перегляд таблиць і підсумковий звіт.
- storage.h, storage.cpp — збереження та завантаження даних через fstream.

## Як запустити у Visual Studio

1. Відкрити файл WorkloadDistribution.sln.
2. Обрати конфігурацію Debug | x64.
3. Натиснути Ctrl + F5.

## Як запустити через g++

g++ -std=c++17 main.cpp data.cpp ui.cpp report.cpp storage.cpp -o workload
./workload

## Функції програми

1. Додавання викладача.
2. Додавання дисципліни.
3. Додавання групи.
4. Створення запису навантаження.
5. Перегляд викладачів, дисциплін, груп і записів.
6. Пошук за ключовим словом.
7. Підсумковий звіт по викладачах.
8. Збереження даних у текстові файли.

## Файли даних

Після завершення роботи програма створює або оновлює файли teachers.txt, subjects.txt, groups.txt, workloads.txt.
Формат простий: поля розділяються символом ;
